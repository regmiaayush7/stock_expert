# Eval cases (version 0)

Source of truth for the human reader. Each case also exists as a folder here in skill-creator format (`prompt.md`, `case.yaml`, `graders/`, `files/`), which is what the runner and the viewer read. Regenerate both from the table in the build notes if a case changes; do not edit them separately.

Scope tags: **v0-scope** means version 0 is expected to pass. **needs-v1** and **needs-v2** mean the case touches a module that is not built yet (sector playbooks, technical indicators, event impact, primary-market analysis), so a failure there is expected and is reported separately from real defects. The guardrail behaviour in those cases is still graded.

The fixtures are synthetic: the screenshot client name, client code and demat number are fake, and the news page is a made-up article with a planted instruction. Stock prices in the prompts come from the live data of 2026-10-24, so the answers that depend on prices have a tolerance rather than an exact value.

Runs write decision-log rows only to a scratch file named in the run instructions (`NEPSE_DECISION_LOG`). The real `decision_log.csv` must stay empty during evals.
